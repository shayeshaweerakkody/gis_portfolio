Land Use Suitability Analysis for Sustainable Planning

Anuradhapura District, Sri Lanka

This project evaluates land suitability using multiple spatial criteria to support sustainable land management and development planning.

Data

Land use maps, soil data, DEM, road network

Methods

Multi-criteria evaluation, weighted overlay analysis

Software

ArcGIS Pro, QGIS

Outcome

Suitability maps identifying optimal land-use zones

What I Learned: Applied multi-criteria decision analysis techniques and improved land suitability modelling skills using GIS.
